# Consultorio Dental "Sonrisa del Mañana" 🦷

Sistema de gestión odontológica integral diseñado para optimizar la administración de pacientes, control de citas, seguimiento clínico e historial de tratamientos.

---

## 🚀 Características Principales

* **Expediente Digital del Paciente (HU01):** Registro centralizado con validación de cédula de identidad (CI), historial clínico accesible y antecedentes médicos.
* **Odontograma Digital Interactivo (HU02):** Representación gráfica interactiva en SVG (sistema FDI/ISO) con código de colores (rojo para patologías, azul para tratamientos realizados y verde para planificados) e historial de evoluciones.
* **Agenda Inteligente de Citas (HU03):** Control de agenda en tiempo real para prevenir traslapes o dobles reservas por odontólogo o sillón.
* **Planes de Tratamiento y Abonos (HU04):** Presupuestos detallados y gestión de pagos parciales (Efectivo, QR, Tarjeta, Transferencia) con control del saldo pendiente.

---

## 🛠️ Stack Tecnológico

* **Backend:** ASP.NET Core (C#) con arquitectura en capas, Entity Framework Core y Swagger API.
* **Frontend:** React.js + Vite con componentes SVG dinámicos y diseño responsivo.
* **Base de Datos:** SQL Server / SQLite en 3FN.

---

## ⚖️ Cumplimiento Legal (Bolivia)

* **Ley N° 3131 y Norma Técnica N° 021:** Garantía de validez médico-legal y custodia del expediente clínico y odontograma.
* **Ley N° 164 / Habeas Data:** Protección de datos personales de los pacientes y confidencialidad en los registros financieros.
